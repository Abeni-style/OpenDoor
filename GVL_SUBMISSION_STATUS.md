# Global Venture League 2026 — OpenDoor project status

**Team:** 5GOLDS  
**Venture:** OpenDoor  
**Event date stated by the organizers:** 22 November 2026 · Online

## Demonstrable in the 5.2.0 prototype
- Responsive dark homepage and guided product tour.
- Opportunity Explorer with 52 discovery leads, real-time text search, filters, CSV/JSON import and full catalogue export.
- Rules-based Smart Matcher with accurate match / mismatch / unknown labels.
- Student Development Academy: 12 courses, 36 lessons and 24 quizzes.
- Prepare & Apply guidance and templates.
- Local student workspace: profile, saved opportunities, application statuses, planner and backup tools.
- Offline OpenDoor Guide for common questions. This is a rule-based offline guide, not live generative AI.
- Local feedback submission and private preview.

## Source code included, but requires deployment/configuration
- Supabase database, passwordless email authentication and Edge Functions.
- Server-side generative AI endpoint.
- Moderated shared reviews.
- Hosted subscription checkout and webhook.
- Scheduled opportunity-feed discovery.

These integrations are not live until an authorized administrator configures provider credentials, deploys them and completes testing. Premium checkout remains intentionally locked.

## Opportunity data integrity
- The 52 initial entries are discovery leads, not confirmed open calls.
- Current-cycle age, country, grade, funding, fee and deadlines are not verified for most entries.
- The source registry is a list of sources to review; it is not proof that all are active or approved feeds.
- The 500-row student-program sample is not an opportunity dataset and is not evidence of real student outcomes.

## Accurate presentation language
Use “interactive website prototype”, “rules-based matcher”, “offline guidance assistant”, “backend integration code prepared” and “planned/awaiting deployment” where appropriate. Do not claim production accounts, live generative AI, public shared reviews, payments or worldwide automatic synchronization are active.
